SOULINK LOGO
============

Put your logo image here and name it exactly:

    logo.png

(A transparent-background PNG looks best. Any aspect ratio works —
the site sizes it by height and scales the width automatically.)

It is used automatically in:
  - Navbar
  - Hero loading animation (preloader)
  - Final CTA section
  - Footer

Until logo.png exists, the site shows a styled "Soulink" text wordmark
as a fallback, so nothing looks broken.

Favicon: replace app/icon.svg with your own icon if you'd like
(you can use app/icon.png instead — Next.js picks up either).
